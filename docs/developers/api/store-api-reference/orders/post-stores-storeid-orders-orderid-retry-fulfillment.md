# Retry order fulfillment

Re-runs fulfillment for an order whose initial fulfillment attempt failed. Requires the `ORDERS_WRITE` scope.

<Api>

<Endpoint method="POST" path={'/stores/{storeId}/orders/{orderId}/retry-fulfillment'} baseUrl="https://api.pandabase.io/v2/core" />

## Authentication

Requires a bearer token (sk_...) or an API key in the header `Authorization`.
